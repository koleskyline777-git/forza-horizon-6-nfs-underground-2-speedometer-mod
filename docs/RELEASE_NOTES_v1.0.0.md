# v1.0.0 — Initial release

**Forza Horizon 6 Need For Speed Underground 2 Speedometer Mod**

## What's included

- Pixel-accurate NFSU2 race HUD overlay for FH6 (AC NFSU2HUD 3.0 art)
- UDP Data Out telemetry (port 20777)
- Tray app, click-through, move/resize, mph/kph, demo mode
- RPM faces for cars and high-rev bikes (~20k)

## Install

1. Unzip the release
2. Follow **ASSETS.md** — copy NFSU2HUD 3.0 `img` → `Assets\AcHud`
3. Enable FH6 Data Out → `127.0.0.1:20777`
4. Run `Nfsu2ForzaHud.exe`

## Hotkeys

F1 HUD · F2 units · F3 demo · F4 move/resize · F9 quit
